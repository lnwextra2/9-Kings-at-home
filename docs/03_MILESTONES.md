# Kingdom Battle — Milestones

> เดินทีละขั้น **จบแล้วต้องรันเห็นผลก่อนไปต่อ** ห้ามข้าม ห้ามทำล่วงหน้า
> ทุก milestone จบด้วย "สิ่งที่ผมกดรันแล้วเห็น" ไม่ใช่ "โค้ดที่เขียนเสร็จ"

---

## M0 — โครงโปรเจค + กระดาน
**เป้า:** เปิด Godot แล้วเห็นกระดาน 5×5

- [ ] เปลี่ยนชื่อ project → **Kingdom Battle** + ตั้ง resolution, main scene
- [ ] โครงโฟลเดอร์ตาม architecture doc (สร้างโฟลเดอร์เปล่าไว้ก่อนได้)
- [ ] `CardData` schema (มี `base_count`, `growth_*`, `abilities`) + การ์ดตัวอย่าง 1 ใบ (`.tres`)
- [ ] `GameState` เปล่าๆ (มี `base_hp = 3`) + autoload `Game`
- [ ] `board_view` วาดกริด 5×5 — **เริ่ม 3×3 กลางปลดล็อก, วงนอก 16 ช่องล็อก** (สีต่างกัน)

**รันแล้วเห็น:** กระดาน 5×5 ปลดล็อก 3×3 กลาง วงนอกล็อก คลิกได้ (ยังไม่มีอะไรเกิดขึ้น)

---

## M1 — วางการ์ด + merge
**เป้า:** เล่นเฟส planning ได้จริง

- [ ] `Content` registry สแกนโหลด `.tres` อัตโนมัติ
- [ ] **การ์ดสีฟ้าครบทุก kind ~8 ใบ** (ฐาน, ทหาร melee/ranged, ป้อม, กำแพง, ฟาร์ม, buff, tome) — ให้ร้าน/สนามมีของครบ
- [ ] `hand_view` แสดงการ์ดในมือ เลือกได้
- [ ] `Board.place()` — วางลงช่องว่าง (เฉพาะช่องปลดล็อก)
- [ ] **กฎการ์ดฐาน:** บังคับวาง wave 0, ตัวเดียว, ทำลายไม่ได้, การ์ดฐานใบใหม่บังคับซ้อนฐานเดิม
- [ ] **merge**: วางการ์ดชนิดเดียวกันทับ → level +1 (cap 3) + `Stats.level_up` mutate cur_*
- [ ] แสดง level บนการ์ดในกระดาน

**รันแล้วเห็น:** วางฐาน wave 0, หยิบการ์ดวางลงกระดาน วางซ้ำขึ้น Lv2/Lv3

---

## M2 — สนามรบ (หัวใจของเกม)
**เป้า:** กดจบเทิร์นแล้วดูกองทัพสู้กันจริง

- [ ] `Spawner` แปลงกระดาน → ยูนิต SoA (soldier count = `base_count × level`, โครงสร้าง = 1) + bake `cur_*`/abilities
- [ ] `WaveGen` สร้างเวฟศัตรูง่ายๆ ตาม floor
- [ ] `Combat.tick()` — หาเป้า (spatial hash) / เดิน / โจมตี / projectile (ranged)
- [ ] `battlefield_view` **`MultiMeshInstance2D` + procedural anim** (เดินเด้ง/ตีเอียง 45°) + HP bar กำแพง/บอส
- [ ] **ลำดับเป้าศัตรู** ทหาร→กำแพง→ฐาน + **ศัตรูแตะฐาน = จบเวฟ, base_hp −1** / เราตายหมด→ศัตรูวิ่งเข้าฐาน
- [ ] เงื่อนไข: ศัตรูตายหมด = ชนะเวฟ / HP บ้าน = 0 = จบ Run
- [ ] `Stats` — mutate current + bake ลง SoA (ดู architecture ข้อ 5)

**รันแล้วเห็น:** กดสู้ → หน้าสนามรบ → ยูนิตวิ่งสู้กัน ตาย → ขึ้นผลแพ้/ชนะ + HP บ้านลด

---

## M3 — วงจรครบ + เศรษฐกิจ
**เป้า:** เล่นวนได้หลาย floor จนแพ้

- [ ] `TurnResolver` ยิง `on_end_turn` — `EffectData` tier 1 ใช้งานได้ (ฟาร์มให้ทอง, บัฟ % stat)
- [ ] ทอง: รายได้ + ใช้จ่าย (**ไม่มีโบนัสชนะ** — แพ้/ชนะได้เท่ากัน)
- [ ] ร้านค้า: ซื้อการ์ด + reroll
- [ ] หน้า reward: สุ่ม 3 เลือก 1 + reroll (ราคา +10g รีเซ็ตทุกหน้า) — **ได้เท่ากันทั้งแพ้/ชนะ**
- [ ] **ระบบ tome/buff ใช้กับการ์ดบนกระดาน** (tome เพิ่ม stat, buff เพิ่ม ability ให้ทหาร)
- [ ] **HP บ้าน 3 ดวงทำงานเต็ม** (แพ้เวฟ −1, จบ Run เมื่อ 0)
- [ ] wave scaling ตามสูตรจริง: `scale = (1+(floor-1)×0.13) × 1.062^(floor-1)`, `count = 3 + ceil(floor²×0.24)`
- [ ] หน้าสรุป Run ตอนจบ + เริ่มใหม่
- [ ] 💥 **Stress test ~3,000 ยูนิต ต้องได้ 60 FPS** — ไม่ผ่านห้ามไปต่อ

**รันแล้วเห็น:** เล่นได้ตั้งแต่ floor 1 จนแพ้ ครบทุกเฟส มีทอง มีร้าน มีรางวัล

---

## M4 — ระบบสี + เนื้อหา
**เป้า:** เกมมีความลึกเชิงกลยุทธ์

- [ ] ระบบสีเวฟ: สุ่มสีศัตรู, ศัตรูใช้การ์ดสีนั้น
- [ ] reroll สีศัตรู (10g เพิ่มถาวรครั้งละ 10g)
- [ ] reward เป็นสีเดียวกับศัตรูที่เพิ่งสู้
- [ ] **ปลดล็อกช่องกระดาน** (อีเวนต์ / tome) — วงนอกจาก 3×3 → 5×5
- [ ] เริ่มสีที่ 2 (สีฟ้าครบตั้งแต่ M1 แล้ว)
- [ ] hook script tier 2 ตัวแรก (เลือกการ์ดที่ logic ซับซ้อนสัก 1 ใบ)

**รันแล้วเห็น:** เลือกรีโรลสีศัตรูก่อนสู้ ชนะแล้วได้การ์ดสีนั้น

---

## M5 — Polish + Save
**เป้า:** MVP สมบูรณ์

- [ ] save/load (`to_dict` / `from_dict` → JSON)
- [ ] seedable run (กรอก seed ได้ผลเหมือนเดิมเป๊ะ)
- [ ] juice: ตัวเลข damage เด้ง, ยูนิตตายมี effect, สั่นจอตอนบอส
- [ ] SFX + เพลง
- [ ] **บอสเวฟ** — แพ้เวฟ Boss = เสีย 3 HP รวด (จบ Run)
- [ ] (ทางเลือก) อัปมุมกล้องเป็น 2.5D/ไอโซเมตริก

**รันแล้วเห็น:** ปิดเกมแล้วเปิดมาเล่นต่อได้ เกมรู้สึกดีขึ้นชัดเจน

---

## หลังจากนั้น (ขยายด้วย data ล้วน)
เพิ่มสีที่เหลือ → เพิ่มการ์ดสีละ 8-10 ใบ → บอสหลายแบบ → meta progression

**ถ้าทำ M0–M5 ถูกต้อง ทั้งหมดนี้ควรเป็นแค่การเพิ่มไฟล์ `.tres`**
ถ้าพบว่าต้องแก้ `core/` เพื่อเพิ่มการ์ด = สถาปัตยกรรมมีปัญหา ให้หยุดคุยกันก่อน
