# Kingdom Battle — Milestones

> เดินทีละขั้น **จบแล้วต้องรันเห็นผลก่อนไปต่อ** ห้ามข้าม ห้ามทำล่วงหน้า
> ทุก milestone จบด้วย "สิ่งที่ผมกดรันแล้วเห็น" ไม่ใช่ "โค้ดที่เขียนเสร็จ"

---

## M0 — โครงโปรเจค + กระดาน
**เป้า:** เปิด Godot แล้วเห็นกระดาน 5×5

- [ ] `project.godot` ตั้ง resolution, main scene
- [ ] โครงโฟลเดอร์ตาม architecture doc (สร้างโฟลเดอร์เปล่าไว้ก่อนได้)
- [ ] `CardData` schema + สร้างการ์ดตัวอย่าง 1 ใบ (`.tres`) พอให้เห็นว่า data-driven ทำงาน
- [ ] `GameState` เปล่าๆ + autoload `Game`
- [ ] `board_view` วาดกริด 5×5 มีช่องล็อก/ช่องว่างต่างสีกัน

**รันแล้วเห็น:** กระดาน 5×5 มีช่องล็อกบางช่อง คลิกได้ (ยังไม่มีอะไรเกิดขึ้น)

---

## M1 — วางการ์ด + merge
**เป้า:** เล่นเฟส planning ได้จริง

- [ ] `Content` registry สแกนโหลด `.tres` อัตโนมัติ
- [ ] การ์ดสีฟ้า 4 ใบ: ทหาร 2 (พลดาบ/พลธนู), ป้อม 1, สิ่งก่อสร้าง 1
- [ ] `hand_view` แสดงการ์ดในมือ เลือกได้
- [ ] `Board.place()` — วางลงช่องว่าง
- [ ] **merge**: วางการ์ดชนิดเดียวกันทับ → level +1 (cap 3)
- [ ] แสดง level บนการ์ดในกระดาน

**รันแล้วเห็น:** หยิบการ์ดจากมือ วางลงกระดาน วางซ้ำแล้วขึ้น Lv2/Lv3

---

## M2 — สนามรบ (หัวใจของเกม)
**เป้า:** กดจบเทิร์นแล้วดูกองทัพสู้กันจริง

- [ ] `Spawner` แปลงกระดาน → ยูนิต (Lv1=1, Lv2=3, Lv3=9 ตัว)
- [ ] `WaveGen` สร้างเวฟศัตรูง่ายๆ ตาม floor
- [ ] `Combat.tick()` — หาเป้า / เดิน / โจมตี / projectile สำหรับ ranged
- [ ] `battlefield_view` วาดทุกอย่างใน `_draw()` ตัวเดียว + HP bar
- [ ] เงื่อนไขจบ: ศัตรูตายหมด = ชนะ / ศัตรูถึงฐาน หรือ เราตายหมด = แพ้
- [ ] `Stats` pipeline (level scaling แบบ compound)

**รันแล้วเห็น:** กดปุ่มสู้ → สลับไปหน้าสนามรบ → ยูนิตวิ่งเข้าหากัน ยิงกัน ตาย → ขึ้นผลแพ้/ชนะ

---

## M3 — วงจรครบ + เศรษฐกิจ
**เป้า:** เล่นวนได้หลาย floor จนแพ้

- [ ] `TurnResolver` ยิง `on_end_turn` — `EffectData` tier 1 ใช้งานได้ (ฟาร์มให้ทอง)
- [ ] ทอง: รายได้ + โบนัสชนะ + ใช้จ่าย
- [ ] ร้านค้า: ซื้อการ์ด + reroll
- [ ] หน้า reward: สุ่ม 3 เลือก 1 + reroll (ราคาเพิ่มครั้งละ 10g รีเซ็ตทุกหน้า)
- [ ] wave scaling ตามสูตรจริง: `scale = (1+(floor-1)×0.13) × 1.062^(floor-1)`, `count = 3 + ceil(floor²×0.24)`
- [ ] หน้าสรุป Run ตอนแพ้ + เริ่มใหม่
- [ ] 💥 **Stress test 300 ยูนิต ต้องได้ 60 FPS** — ไม่ผ่านห้ามไปต่อ

**รันแล้วเห็น:** เล่นได้ตั้งแต่ floor 1 จนแพ้ ครบทุกเฟส มีทอง มีร้าน มีรางวัล

---

## M4 — ระบบสี + เนื้อหา
**เป้า:** เกมมีความลึกเชิงกลยุทธ์

- [ ] ระบบสีเวฟ: สุ่มสีศัตรู, ศัตรูใช้การ์ดสีนั้น
- [ ] reroll สีศัตรู (10g เพิ่มถาวรครั้งละ 10g)
- [ ] reward เป็นสีเดียวกับศัตรูที่เพิ่งสู้
- [ ] การ์ดสีฟ้าครบ ~8 ใบ + เริ่มสีที่ 2
- [ ] tome/buff ระบบใช้กับการ์ดบนกระดาน
- [ ] hook script tier 2 ตัวแรก (เลือกการ์ดที่ logic ซับซ้อนสัก 1 ใบ)

**รันแล้วเห็น:** เลือกรีโรลสีศัตรูก่อนสู้ ชนะแล้วได้การ์ดสีนั้น

---

## M5 — Polish + Save
**เป้า:** MVP สมบูรณ์

- [ ] save/load (`to_dict` / `from_dict` → JSON)
- [ ] seedable run (กรอก seed ได้ผลเหมือนเดิมเป๊ะ)
- [ ] juice: ตัวเลข damage เด้ง, ยูนิตตายมี effect, สั่นจอตอนบอส
- [ ] SFX + เพลง
- [ ] บอสเวฟ

**รันแล้วเห็น:** ปิดเกมแล้วเปิดมาเล่นต่อได้ เกมรู้สึกดีขึ้นชัดเจน

---

## หลังจากนั้น (ขยายด้วย data ล้วน)
เพิ่มสีที่เหลือ → เพิ่มการ์ดสีละ 8-10 ใบ → บอสหลายแบบ → meta progression

**ถ้าทำ M0–M5 ถูกต้อง ทั้งหมดนี้ควรเป็นแค่การเพิ่มไฟล์ `.tres`**
ถ้าพบว่าต้องแก้ `core/` เพื่อเพิ่มการ์ด = สถาปัตยกรรมมีปัญหา ให้หยุดคุยกันก่อน
