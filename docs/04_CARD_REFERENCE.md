## Legend — ความหมายของ field & flag
- **count**: จำนวนทหารที่สปอว์น = **`base_count` ตรงๆ** → `cur_count = base_count × level` (Lv1 = base_count, Lv2 = 2×, Lv3 = 3×)
- **hp / dmg**: เลือด / ดาเมจต่อครั้ง (ค่า base Lv1)
- **range**: ระยะโจมตี (px) — melee ~26, ranged 200-400
- **atkCd**: คูลดาวน์โจมตี (วินาที/ครั้ง) ยิ่งน้อยยิ่งตีเร็ว
- **move**: ความเร็วเดิน (px/วิ) — 0 = อยู่กับที่
- **crit**: โอกาสคริติคอล
- **growth**: การโตต่อเลเวล (compound) — `hp/dmg/aps/move/crit`
- **tFar** = เล็งศัตรูไกลสุดก่อน · **tBack** = เล็งแถวหลังก่อน
- **isKamikaze** = พลีชีพระเบิด · **isDemon/isSummon** = ปีศาจที่ถูกอัญเชิญ
- **baseSplash / splash** = รัศมี AoE · **goldOnDeath** = ตายแล้วให้ทอง
- **isBase** = ฐานหลัก (ทำลายไม่ได้)

**คำอธิบายพิเศษ (ทหารที่มี desc):**

- **Bomber**: วิ่งตรงหาศัตรู ระเบิดพลีชีพวงกว้าง (ถ้าตายก่อนถึงก็ระเบิด)

- **Trapper** *(กลไกกำหนดเพิ่มโดยผู้เล่น — Godot)*: เริ่มรบวางระเบิดสุ่มกระจายหน้ากำแพง 3 ลูก/ตัว (สะสมข้ามเวฟ ไม่มีลิมิต) · ศัตรูเข้าใกล้ (รัศมี/2) = ระเบิด AoE (รัศมีเต็ม) dmg = attack · แล้ววิ่งไปสู้ตัวเปล่า

- **ปีศาจ**: summon จาก demongate · ทหารตายเพิ่ม demonStat

- **หมูป่า**: สามารถถูกขี่โดยทหารรอบๆ เพิ่ม +1% stat ต่อ 1 hp ของหมูป่าให้ผู้ขี่

- **Mob**: ทหารรอบข้างได้ addCount → Mob ได้ addCount เท่ากัน

- **แรปเตอร์**: พาหนะ รวม stat กับผู้ขี่ · เริ่มรบพุ่งทะลุแนวหน้าไปหลัง

- **ผู้ปกป้อง**: ไม่โจมตี · สะท้อนดาเมจ · HP x2/level

- **หนูทดลอง**: ไม่มี max level · โดนอัพจะแพร่ level ให้หนูข้างเคียง

- **แพะ**: ไม่โจมตี · เดินเรื่อยๆ อยู่แถวหลัง ตอนตายให้ทอง 3g/level
